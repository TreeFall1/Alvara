# SharpLink Homepage Rebuild

A static, responsive recreation of the SharpLink homepage built with Next.js App Router, GSAP, Lenis, Lottie, Chart.js, Embla and Three.js.

## Development

```bash
npm install
npm run dev
```

## Verification

```bash
npm run typecheck
npm run lint
npm test
npm run build
npx playwright install chromium
npm run test:e2e
```

All public-facing links are intentionally visual-only. Dashboard figures and news are a static snapshot dated August 31, 2026.
